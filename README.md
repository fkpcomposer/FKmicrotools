# FKmicrotools
Janky extensions for the micro:bit I made for fun :3

## Extensions
- [Filters](https://github.com/fkpcomposer/FKmicrotools/blob/main/extensions/filters.ts): Apply visual effects to whatever is on screen
- [Waves](https://github.com/fkpcomposer/FKmicrotools/blob/main/extensions/waves.ts): Easily write and play music on the micro:bit
